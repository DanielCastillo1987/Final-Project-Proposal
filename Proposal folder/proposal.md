# Tiktaktoe

https://github.com/DanielCastillo1987/Final-Project-ANGM-2305.0W1---PROGRAMMING-FOR-DIGITAL-ARTS-.git 

## Description
You and the AI opponent will battle it out in tictaktoe but with a few twists.
The first is how you and the AI will be able to select one of four classes, the second
is you will be able to play over moves if all the spaces are filled up and the oldest move of yours will be removed.  

## Features
- Basic Tiktactoe
	- First I would like to write the code for a base tiktactoe game that you can play with your AI opponent.
    I will expand on this once I get the backbone done.  
- Ability to play over moves
	- Once the board is filled and no one has won yet you the next move can be played over an already done move.
- Classes
	- You will be able to select one of four classes Knight, Thief, Wizard, John tiktactoe. The first three will have each a unique ability.
    When John is just normal tiktactoe.

## Challenges
- How to create a basic tiktactoe game to work as a building block.
- How to creat code so we can play over already done moves only once the board is filled.
- How to make the classes ability work in game.
- The most diffcult one is how to make the AI make moves and work with the classes ability.

## Outcomes
Ideal Outcome:
- In the best case scenario I would have a fully functional best out of five tictaktoe game to decide the winner with the aforementioned features. 

Minimal Viable Outcome:
